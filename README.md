# AI Business Assistant 🚀

A full-stack AI-powered business assistant that helps small businesses generate marketing content, product descriptions, social media posts, and business ideas.

## 🌐 Live Demo

https://ai-business-assistant-sigma.vercel.app/

## 💻 GitHub

https://github.com/Pravallika-Varada/ai-business-assistant

## ✨ Features

- Business information collection
- AI-generated social media content
- Marketing email generation
- Product descriptions
- Business growth ideas
- Real-time backend health status
- Responsive React interface
- FastAPI backend
- Secure API key handling with environment variables

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Python
- FastAPI
- Uvicorn
- OpenAI API

### Deployment
- Vercel
- GitHub
